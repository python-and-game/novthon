# Update

- Warping between options is improved!
+ Move down below the bottom option: Jumps up to the top option
+ Move up above the top option: Jumps down to the bottom option

- We now have 2 demo games:
+ The Default Game
+ The Soda Saga (new)

- To access games, you have to use: 
```
python game.py <a folder containing a `data` directory>
```

- To install the `novel_lib` as a python package, use:
```
cd Novel_Python
pip install .
```

- Fading was kinda changed in some ways in the coding format but mostly
the same (it can be skipped by pressing 'ok' key (default is K_SPACE and K_RETURN)
but it isn't really effective, you should press it fast if you wanted to skip transitions
